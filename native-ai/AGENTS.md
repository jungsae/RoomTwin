# Native AI 개발 지침

이 디렉터리에는 [루트 AGENTS.md](../AGENTS.md)의 공통 규칙과 아래 모듈 지침이 적용된다.

## Kotlin과 Android

- 독립 앱의 빌드와 실행은 `native-ai/`에서 가능해야 한다. 빌드 도구와 의존성 버전을 고정하고 바꿀 때는 README의 재현 절차도 갱신한다.
- Activity는 입력 처리와 화면 표시를 맡는다. 이미지 디코딩, 모델 초기화, 추론, 리소스 해제는 작업 스레드에서 실행한다.
- 화면을 닫거나 다시 만들 때 완료된 작업이 이전 화면을 갱신하지 않도록 한다. 네이티브 추론과 세션 종료를 직렬화한다.
- 사용자 파일은 시스템 선택기나 앱 전용 저장소로 받는다. 프롬프트, 이미지 내용, 모델 응답, 인증 정보는 로그에 남기지 않는다.

## LiteRT-LM과 Gemma 4 E2B

- 고정한 Android AAR 버전의 공식 API와 모델 카드에서 예제 및 호환성을 확인한다. 버전을 바꿀 때는 Gradle 컴파일과 실기기에서 모델 로드 및 추론을 다시 확인한다.
- 작업 스레드에서 `Engine`을 초기화하고, 추론마다 `Conversation`을 생성해 사용 후 닫는다. 모든 대화가 끝난 뒤 엔진을 닫는다.
- CPU를 초기 검증 기준으로 삼는다. 다른 백엔드를 추가할 때는 실제 사용 백엔드와 실패 원인을 확인할 수 있어야 한다.
- Gemma 4 E2B IT의 LiteRT-LM 배포 파일을 외부에서 공급한다. 모델 누락, 읽기 실패, 초기화 실패와 응답 실패는 사용자가 구별할 수 있게 표시한다.
- 실기기 검증에는 기기·OS·ABI, 모델 리비전과 파일 해시, 런타임 버전, 백엔드, 입력 유형과 결과를 기록한다. 성능 수치는 측정 조건을 함께 기록한다.
